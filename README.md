# ☕ Coffee Shop Sales Analysis

A lightweight Python data analysis project simulating weekly sales insights for a local coffee shop.

## 📌 Project Overview
This project processes raw daily sales data using **Pandas** to extract key business metrics such as total revenue, top-selling items, and product-level financial contributions.

## 🚀 Key Findings & Insights
- **Total Revenue:** 15,050 TL
- **Top Product by Volume:** Latte (125 units)
- **Top Product by Revenue:** Latte (8,750 TL — ~58% of total weekly revenue)
- **Business Insight:** Croissant generated high revenue despite only being sold 2 days a week. Offering Croissant daily could significantly boost weekly revenue.
